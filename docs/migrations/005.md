## 0. Rev 2 — Codex rev-1 findings
| # | Finding | Change | Control |
|---|---|---|---|
| P1 | The grant path rewrote `gated_actions.caller_integration`, so another authenticated integration could take an action key over (e.g. after `failed_definitive`) | An action is **bound** to the integration that first presented its key: a different integration is denied `wrong_integration` (event kept, no attempt) **before** the state table; the grant no longer rewrites the binding; `gated_actions_guard` makes key, iD, action and binding immutable at the DB boundary | Y2n (other integration during a grant → `wrong_integration`, 1 attempt), Y2o2 (logged), Y2o3 (direct rewrite refused), Y3o2 (takeover after `failed_definitive` refused) |
| P1 (rev-2 follow-up) | Binding the key to its first caller does not prove that caller was eligible for the action | New `gate_integration_actions(caller_integration, action)` allowlist, checked **first** in `authorize_and_consume` → `integration_not_allowed`; **seeded empty** (D-40): until the owner's S2 inventory lists each app/Zap with its action, nothing is granted | Y2-0 (empty list → every call denied), Y2-1 (listed integration, unlisted action → denied); test rows added for the suite only |
| P2 | Idempotent replay did not check the caller | Replay requires the bound integration (P1 check) **and** the granted attempt's integration to equal the caller, and the action on the proven list | Y3u2 (another integration on a listed target → `wrong_integration`), Y3v (bound integration replays) |

## 1. Design mapping
| Design v0.17 | Objects | Controls |
|---|---|---|
| §6.3 `row_actionable(iD)` | pure helper → `(actionable, reason, deal_id, deal_version)`: linked + canonical + confirmed + `status='current'`; Deal not cancelled/voided; no open hold; no open material draft; latest released version exists; route **read from `source_channels`** (never the `consumer_route` cache): `risk_audit` → `approval_eligible`; `skip_audit` → allowed; anything else denied | Y1a–j (every denial reason), Y1k (a stale cache cannot allow) |
| §6.3 authoritative 3.1 status | The Worker reads the iD's Deal Status from 3.1 and passes `read_31_status` / `read_31_at`; the function denies on a missing read, a read older than `system_settings.gate_31_read_max_age_seconds` (60, D-35), a status not in `legacy_31_statuses` (fail closed, D-34) or one marked inactive; the caller's own `row_status` is recorded on the attempt and in the event with `status_mismatch`, never decisive | Y2b–e, Y2k–l |
| §6.2 `authorize_and_consume` | `(action_key, iid, action, caller_integration, caller_run_ref, triggered_by, supplied_row_status, read_31_status, read_31_at) → jsonb`. Lock order Deal **FOR SHARE** → `gated_actions` row **FOR UPDATE** (the row is created on first sight with `ON CONFLICT DO NOTHING`, so concurrent callers for one key serialize on it). State table implemented in the design's order: granted attempt outstanding → `in_progress` for every caller and run (**same-run replay not enabled**), except an action on the proven-idempotent list (`gate_idempotent_targets`, seeded **empty**, D-36) → `replay=true`, same attempt; `completed` → `already_completed`; `outcome_unknown` → denied, never retried automatically; `denied` / `failed_definitive` → fresh eligibility → new attempt N+1 or a new denial event. Every call is a `gated_action_events` row; denials keep their action row. `action_key` reuse for another iD/action raises `GATE_KEY_REUSED` | Y2a (args), Y2f (denials kept, 4 events), Y2g–h (hold, unknown iD), Y2i–l (grant facts), Y2m–n (single executor), Y2o (key reuse), Y3f (already_completed), Y3i/Y3r (outcome_unknown never retried), Y3p/Y3t (attempt N+1 after failed_definitive / resolution), Y3u–v (replay only on the proven list) |
| §6.2 single executor | partial unique index `one_granted_attempt_per_action`; attempts guard: grant facts immutable, a terminal attempt never changes state | Y2p, **CONC-5a** |
| §6.2 `report_action_outcome` | `(attempt_id, outcome, evidence, caller_integration, caller_run_ref)`. Wrong integration → **rejected and logged** (`late_report` event, `recorded=false`, state unchanged). `completed` (evidence allowlisted `gate_outcome_evidence`, D-37) / `failed_definitive` (the only retryable outcome) / `failed_ambiguous` → `outcome_unknown` + work item. A report for a non-current or finished attempt is late evidence (event only); a **different** outcome on a finished current attempt is a conflict → `outcome_unknown` + `gate_conflicting_reports` work item, both reports kept | Y3a–e, Y3g–h, Y3o, Y3q, Y3s, Y4c |
| §6.2 timeout | `expire_stale_attempts(now)` (Worker schedule): granted attempts older than `gate_attempt_timeout_seconds` (600) → `outcome_unknown` + work item; a later report is late evidence | Y4a–c, T56 5b |
| §6.2 "resolved by Data Entry" | `resolve_unknown_outcome(action, 'completed' \| 'failed_definitive', evidence, reason, actor)` (data_entry): records what happened; `failed_definitive` makes a fresh authorization possible; closes the action's open gate work items | Y3j–m, Y3t |
| §6.4 sweep (the dependency 002 named) | `open_hold` now calls `_sweep_unfinished_actions`: every action of the Deal with a granted attempt or in `outcome_unknown`, regardless of age → `gate_unfinished_action` work item (one open per action) + `swept` event. **Nothing is released or changed on the action.** A `completed` report whose attempt was granted before a hold opened → `completed_after_hold` + event + work item | Y4d–l (sweep lists granted and unknown, not completed; new authorize denied `hold`; late completion flagged; hold released only by the decision), **CONC-5b** |
| §2.2 grants | `tav_worker`: EXECUTE on `authorize_and_consume`, `report_action_outcome`, `expire_stale_attempts` (+ 004's `ingest_vauto_observation`) and nothing else — no table privileges, no helpers, no staff functions; `iit_integration`: `resolve_unknown_outcome`, `set_consignment`; PUBLIC/anon/authenticated nothing | Y7a–d |
| D-32 | `_deal_from_observation` flags a non-two-letter title region (`vauto_title_region_unmapped`, non-blocking); state left empty | Y5 |
| D-30 | `set_consignment(deal, consignor_party_id, amount, notes, actor)` (data_entry): consignor must be a party of the Deal; `manual_consignment` only; pre-release only (D-38); sets `deals.consignment_id`; PR3: never touches `purchase_price` | Y6 |
| §5.9 history | `gated_actions`, `gated_action_attempts` history-covered; `gated_action_events` append-only; new reference tables covered | Y7e |

## 2. Explicitly not here
- **The Worker** (credential verification per integration, the 3.1 Deal Status read, the `Audit Gate` display push with 30-minute CLEAR expiry, the schedule that calls `expire_stale_attempts`): Worker code, reviewed with the Worker. The database functions take the Worker's verified `caller_integration` and its 3.1 read as inputs.
- **Same-run replay** (§6.2 second "granted" row): not enabled; nothing in this migration can enable it without a reviewed change.
- **Attempt `superseded` state:** vocabulary only; no 005 path supersedes an attempt (there is no replay that would).
- §5.8 bridge, §5.10 polling, §5.11 lienholder sync, reschedule linking (D-8).
