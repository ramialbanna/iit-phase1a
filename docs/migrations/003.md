## 2. Explicitly not here
- **§5.8 bridge:** `release_deal` does **not** queue `add_31_row` on first release; the dependency is stated in the function comment, no placeholder exists.
- **§5.7 step 5 "no parser re-run pending":** no parser objects exist in this schema; the check is absent, not stubbed (D-19).
- **§6.4 sweep** in `open_hold` (unchanged from 002: dependency stated).
- **Intake (004):** vAuto intake, draft-1 creation and editing (`release_deal` requires the draft and its facts to exist; the tests insert them directly), seller-party edits (material and administrative), reschedule linking, `restart_candidate` outcomes, `data_entry_due_at`.
- **Two-session race tests** for release vs flag/report change (invariant 21): the design's single-lock argument is implemented (every function takes `deals FOR UPDATE` first); no CONC test was written in this slice.
