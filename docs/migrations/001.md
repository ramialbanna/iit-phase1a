## 2. Explicitly not in this migration (later slices)

## 3. Dependencies on excluded bridge objects (§5.8) — named, not stubbed
- `release_deal()` (future slice) is specified to "queue the initial `add_31_row` delivery on first release". With the bridge deferred it will **not** do that; the slice that adds `release_deal` must state this and provide no placeholder.
- `source_records.created_via = 'bridge'` and `work_items.kind IN ('id_collision','delivery_failed_manual','vin_validation_rejected','duplicate_row')` are vocabulary only; nothing creates them.
- `source_records.legacy_iid` is "NULL until known"; with no bridge it is set only by cutover/manual paths (future slice).
